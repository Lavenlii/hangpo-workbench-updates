# 恆寶旅運報價工作台更新

此倉庫提供工作台程式的版本更新下載。

固定更新資訊網址：

https://github.com/Lavenlii/hangpo-workbench-updates/releases/latest/download/manifest.json

管理員登入工作台後，前往「設定及備份 → 工作台版本及一鍵更新」，保存上述網址，再按「檢查更新」。

工作台會按目前使用的模式下載對應程式：本機版、公司內網版或異地版。安裝前會核對程式檔案並建立資料庫快照。

使用瀏覽器連接同一主機的同事，主機完成更新後重新整理即可。

## 公司共用（v2.1.8 起）

在保存正式資料的公司電腦，開啟「設定及備份 → 公司共用工作台」，按「啟用這台為公司主機」，保存工作後完全關閉、重新開啟 EXE。

本地同事連接公司 Wi-Fi／網線；異地同事與主機需要加入同一個 Tailscale 私人網絡。主機下載「同事連線檔」，同事在新版登入頁按「連接公司主機（首次設定）」匯入一次，不必先登入獨立本機帳戶。

之後同事開啟 EXE 會自動使用公司主機的帳戶、標書、報價及蓋章。主機重設密碼後，同事使用新密碼重新登入；主機更新一次，同事重新整理即可。主機必须保持開機及連線。

同事原有本機資料會保留，不會自動匯入或覆蓋主機。連線檔不含密碼、標書、簽章或資料庫；不要公開轉發。主機斷線只顯示重連，不會開啟另一個空白工作台。

所有公開更新程式均不附帶使用者資料庫、客戶文件或原始示例 PDF。
